# YPerson App Store metadata package

Status: draft for local review. Nothing in this directory has been entered into App Store Connect.

`ru-RU.json` contains copy that matches the implemented Russian UI. The suggested primary category is Business and the suggested secondary category is Social Networking; these remain owner decisions.

Before use, the owner must provide and confirm:

- final registered app name, Bundle ID, SKU, copyright holder, and content-rights attestation;
- live support/moderation and privacy-policy URLs;
- App Review contact name, email, and phone;
- territory/availability, category choices, and the rating generated by the current questionnaire;
- a live review backend and final build/version values.

The `screenshots/` root contains the current upload candidates. `screenshots/source-png/` preserves unmodified Simulator captures and is not the upload set.

Character and format limits are validated during final release verification. Apple metadata and reviewer fields must be rechecked in App Store Connect immediately before entry because its questionnaire and required fields can change.
